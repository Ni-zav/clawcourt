## Current product
- `npm start` serves localhost-only web UI with local receipts.
- Offline false-claim/actual-fix simulations generate clearly labeled receipts.
- `src/openclaw.mjs` launches the documented OpenClaw `agent exec` headless CLI, consumes JSON and records duration/provider/model where returned.
- `src/core.mjs` checks actual workspace files, SHA-256 snapshots and selected allowlisted test commands.
- Eight unit tests currently pass. Real OpenClaw CLI has not yet been smoke-tested on the user's Mac.
